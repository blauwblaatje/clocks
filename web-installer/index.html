CLOCK firmware

CRG-Linked Officials' Clock Kit

Version …

CLOCK runs on two boards, each with its own firmware:

  • Waveshare ESP32-C6-Touch-LCD-1.28 (in the CLOCK case)
  • M5Stack StopWatch (ESP32-S3)

Install over USB

Connect the timer with a USB-C cable and press the button. Needs Chrome or Edge on a computer (Web Serial). This is also how the very first install is done. The page sees which chip it is talking to and installs that board's firmware.

Update without a cable

On the timer: menu, Connection, Update (looks here when the timer has internet, and only at its own board's firmware), or download the firmware for your board and upload it on the timer's setup page:

  • Waveshare ESP32-C6: firmware.bin
  • M5Stack StopWatch: firmware.bin

A timer refuses firmware made for the other board.

For the timers: <board>/latest.json holds the version, size and SHA-256 of that board's firmware.bin.

Release notes

0.3.1 2026-11-20

  • Release notes on this page. The firmware is the same as 0.3.0.

0.3.0 2026-11-20

  • Clock faces: pick how the main screen looks. Besides Classic there are LCD (day, night, night in colour), Big, Big outline, Rings, Chronograph, High contrast, Flip and Nixie, for the jam timer and both box timer roles, on both boards. Menu, Device, Face or the setup page; the face changes at once.
  • Each role keeps its own face. Prefer Big as jam timer and Rings in the box? Switching role brings the face along.
  • Each role keeps its own buttons too: put any of the role's three actions on any button (menu, Device, Buttons or the setup page). Undo and the hold for the menu stay together on one button. Settings from 0.2 carry over.
  • Team colours (setup page): the box timer faces show the team colours set in CRG as an edge and on the team names.
  • Faces with little room show what each button does while you hold a button and for 3 seconds after a press. On the Waveshare, whose buttons sit at the top, every face does this.

0.2.1 2026-11-19

  • M5Stack StopWatch: yellow (11 o'clock) is the main button, blue (1 o'clock) and red (7 o'clock) the other two. Screens name the buttons by their colour.
  • Fixed: the StopWatch crashed on its first connection to a real CRG (also in 0.2.0).
  • Fixed: touch on the StopWatch.
  • The setup page stays on as long as the timer is on a network; Info shows its IP address.
  • The menu opens during intermission. Role changes, updates and automatic sleep still wait for the intermission clock to stop.
  • Clock digits keep the same width, so times no longer shift as they count.
  • Screens redraw faster (a full StopWatch screen in 185 ms instead of 310 ms).

0.2.0 2026-11-18

  • A second board: the M5Stack StopWatch (ESP32-S3, 466 × 466 AMOLED), with its own firmware.
  • Updates come from this site, one folder per board. A timer refuses firmware made for the other board, also when uploaded on its setup page.
  • This page installs the right firmware for the chip it finds.

0.1.0 2026-11-13

  • First release: jam timer and penalty box timers for the Waveshare ESP32-C6-Touch-LCD-1.28, controlling CRG over the network or running on their own.
  • Install over USB from this page, updates over Wi-Fi.
