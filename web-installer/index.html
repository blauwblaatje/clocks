CLOCK firmware

CRG-Linked Officials' Clock Kit

Version …

CLOCK runs on two boards, each with its own firmware:

  • Waveshare ESP32-C6-Touch-LCD-1.28 (in the CLOCK case)
  • M5Stack StopWatch (ESP32-S3)

Install over USB

Connect the timer with a USB-C cable and press the button. Needs Chrome or Edge on a computer (Web Serial). This is also how the very first install is done. The page sees which chip it is talking to and installs that board's firmware.

Update without a cable

On the timer: menu, Connection, Update (looks here when the timer has internet, and only at its own board's firmware), or download the firmware for your board and upload it on the timer's setup page:

  • Waveshare ESP32-C6: firmware.bin
  • M5Stack StopWatch: firmware.bin

A timer refuses firmware made for the other board.

For the timers: <board>/latest.json holds the version, size and SHA-256 of that board's firmware.bin.
