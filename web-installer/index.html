Install over USB

Connect the timer with a USB-C cable and press the button. Needs Chrome or Edge on a computer (Web Serial). This is also how the very first install is done.

Update without a cable

On the timer: menu, Connection, Update (looks here when the timer has internet), or download firmware.bin and upload it on the timer's setup page.

For the timer: latest.json holds the version, size and SHA-256 of firmware.bin.
